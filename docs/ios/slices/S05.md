# S05 — Profile, statistics, settings, and sharing

## Outcome

Users understand and edit their profile, explore personal/group statistics, control appearance, and share a branded leaderboard image.

## Entry criteria

S04 is merged and closed by the first transition commit on `feature/ios-profile-stats`; S05 is the only `in_progress` slice.

## Scope

Implement profile/settings/stats feature groupings, avatar selection/photo permission flow, name editing, attendance/finishes/partners/streaks, theme selection, offscreen share rendering, and native share sheet.

## Public contracts

No planned backend API changes. Preserve current user, avatar, stats, trophies, and update-user contracts.

## UX and state contract

Cover independent section loading/empty/failure, photo permission denied/limited, upload progress/failure, editable-field validation, chart alternatives for VoiceOver, reduced motion, large text, light/dark, share rendering failure, and cancellation.

## Architecture and tests

Inject user/stats/trophy repositories, image picker/processor, appearance store, renderer, and share presenter. Unit-test computations/mapping and image determinism; UI tests cover edits, permissions, state variants, and sharing; compare golden evidence without adding a third-party snapshot framework unless separately approved.

## Exclusions

Push registration, update endpoint, and account deletion.

## Verification evidence

Record Xcode/backend commands, `.xcresult`, JUnit, accessible chart assertions, and screen/share images in both appearances.

## Exit criteria

Profile, settings, all statistics, and sharing are complete, deterministic, accessible, and visually branded.

## Next transition

Create `feature/ios-notifications`; record S05 PR/merge evidence, mark S05 `done`, and start S06.
