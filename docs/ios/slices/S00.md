# S00 — Foundation and delivery controls

## Outcome

A buildable Swift 6, iOS 17+, iPhone-portrait Playboard shell establishes the native architecture, branded design system, deterministic Design Gallery, pinned dependencies, repeatable commands, and unsigned Codemagic delivery path.

## Entry criteria

- Branch `feature/ios-foundation` is based on refreshed `origin/master` commit `57fb317902eb3198423f043aca45977b9f46d2c6`.
- Existing untracked user files remain untouched.
- S00 is the only `in_progress` roadmap row.

## Scope

- Create the shared Xcode project/scheme with app, unit-test, and UI-test targets using Swift 6 strict concurrency, warnings as errors, iOS 17, iPhone only, and portrait only.
- Establish feature-oriented MVVM/Repository directories and the single `AppEnvironment` composition root with deterministic in-memory test/preview dependencies.
- Port Manrope, Paytone One, their OFL licenses, racket wordmark, two crown assets, app-icon source, 16 avatars, semantic palettes, two-glow background, type/spacing roles, cards, buttons, avatars, and loading/empty/error controls.
- Add a debug launch-argument Design Gallery, previews, and a light/dark screenshot UI test.
- Add Google Sign-In `9.2.0..<10.0.0` and Firebase Apple SDK `12.18.0..<13.0.0`, selecting only `GoogleSignIn` and `FirebaseMessaging`, with `Package.resolved` committed.
- Add templates/ignore rules and an Xcode-26.2 Codemagic workflow producing unsigned artifacts.

## Public contracts

No backend or production API changes. No provider SDK is initialized. No real provider, Firebase, APNs, OAuth, signing, or personal configuration is committed.

## UX and state contract

The normal unconfigured app displays a safe foundation screen. `-design-gallery` opens every reusable state. Both light/dark appearances must show all fonts, assets, avatars, semantic colors, controls, text wrapping, non-color state symbols, accessibility labels, scalable text, and minimum 44-point controls.

## Architecture and tests

SwiftUI views render immutable values and emit actions. `@MainActor` view models own UI state in later slices; repository protocols own data boundaries. S00 tests environment injection and palette/font/assets invariants. UI tests launch the gallery in light and dark mode, verify accessibility identifiers, and attach screenshots.

## Exclusions

Authentication, provider initialization, navigation shell, production API calls, persistence of user data, push registration, signing, IPA export, and publication.

## Verification evidence

Run `resolve-packages.sh`, `build.sh`, `test.sh`, `archive-unsigned.sh`, and `verify-repository.sh` under Xcode 26.2. Preserve `build/TestResults.xcresult`, `build/junit.xml`, `build/gallery-light.png`, `build/gallery-dark.png`, `build/Playboard.xcarchive`, dSYMs, and logs.

## Exit criteria

All targets compile and tests pass with warnings as errors; the app runs without provider configuration; both gallery appearances render; Codemagic publishes required unsigned artifacts; repository scans and documentation validation pass; unrelated user files are not staged. S00 remains `in_progress` through its PR.
