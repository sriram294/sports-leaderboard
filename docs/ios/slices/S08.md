# S08 — Release readiness and parity closure

## Outcome

The native iOS client meets the agreed parity, quality, privacy, accessibility, performance, observability, and release-readiness bar.

## Entry criteria

S07 is merged and closed by the first transition commit on `feature/ios-release`; S08 is the only `in_progress` slice.

## Scope

Close parity-matrix gaps, run full regression/accessibility/performance/privacy audits, finalize localization/configuration documentation, validate migration/upgrade behavior, harden CI artifacts, prepare store metadata/checklists, and document the future signed release path.

## Public contracts

No planned new endpoint. Freeze and verify all iOS contracts introduced in S01, S06, and S07 plus existing APIs used in S02–S05.

## UX and state contract

Audit every feature's loading, empty, failure, offline, permission, large-text, VoiceOver, reduced-motion, contrast, light/dark, interruption, and restoration behavior on supported iPhones and iOS versions.

## Architecture and tests

Run all iOS/backend compatibility tests, identify concurrency/data-race warnings, measure launch/scroll/memory/network behavior, validate privacy manifests and dependency licenses, and retain a release candidate evidence bundle. Signing/publication requires separate authorized credentials and remains externally configured.

## Exclusions

Unapproved feature work, backend redesign, credential commits, self-merge, and automatic App Store publication.

## Verification evidence

Record Xcode 26.2/device matrix, complete `.xcresult`/JUnit/log/archive/dSYM bundle, parity screenshots, accessibility audit, performance baselines, secret/signing scan, and release checklist.

## Exit criteria

Every parity-matrix cell is resolved with evidence or an explicitly accepted exception; CI is reproducible; privacy/accessibility/performance checks pass; the unsigned release archive is complete; store signing remains a documented authorized follow-up.

## Next transition

After S08 merges, open one documentation-only closure PR recording its PR and merge commit, marking S08 `done`, clearing `memory.md`, and confirming no slice remains `in_progress`.
